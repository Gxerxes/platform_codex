# Palette 业务应用接入指南（草案）

## 接入流程

1. 提供业务应用名称、标识、环境和负责人。
2. 确认身份源及角色/权限映射。
3. 确认 BFF 与下游的部署拓扑。
4. 注册受控下游服务，不允许任意代理地址。
5. 配置登录、回调、登出及安全 Cookie。
6. 定义统一错误、重试、超时和降级策略。
7. 接入日志、指标、关联 ID 和审计字段。
8. 完成本地 Mock、集成安全测试及生产前评审。

## 接入信息清单

- 应用标识
- 环境
- 回调和登出 URL
- OIDC Client 占位配置
- 下游服务注册名和可信地址
- 必需角色和权限
- 请求超时
- 重试范围
- 错误映射
- 日志脱敏要求
- 审计事件
- 兼容性与回滚要求

## 不应由业务应用自行实现

- Access Token 和 Refresh Token 保存。
- OAuth2 OIDC 登录流程。
- 浏览器端敏感令牌处理。
- 任意下游代理目标。
- 跨应用共享 Cookie 或 Session 秘密。
- 绕过后端权限校验的功能开关。

## 接入验收

- 未登录访问受保护资源返回明确 401。
- 已登录但无权限返回明确 403。
- Session、令牌过期及刷新可验证。
- 登出清理 Session 与认证状态。
- 下游异常可映射为一致错误。
- 日志不泄露令牌、Cookie 或密钥。
